## Reglas Generales (aplican a todos los tracks)
1. **Originalidad** — El proyecto debe desarrollarse desde cero durante el hackathon. No se aceptan trabajos previos, proyectos reutilizados ni plagios.
1. **Uso de la tecnología del track** — Cada track tiene requisitos mínimos de integración técnica específicos (ver sección de cada track).
1. **Código abierto** — Repositorio público obligatorio en GitHub con documentación clara (README, instrucciones de instalación, despliegue y testing).
1. **Pitch y presentación** — Los finalistas tendrán hasta **5 minutos** para presentar, seguido de **2 minutos de Q&A** con el jurado.
1. **Entregables vía DoraHacks** — Cierre: **viernes 27 a las 17:00 hs.** Subir todo con al menos 30–40 minutos de anticipación. Sin excepciones.
### Entregables Minimos para Hackathon (todos los tracks)

## Hedera — Hackathon
### Descripcion del Track: "Pagos a traves de Agentes de IA"
Estamos ingresando en una nueva era de internet: un lugar cada vez más agéntico, donde los usuarios delegan decisiones en agentes de inteligencia artificial. Estos agentes no solo informan o recomiendan, sino que buscan, negocian, toman decisiones y ejecutan acciones en nombre de las personas y las organizaciones.

**La pregunta central:** ¿cómo se gestionan los pagos en un mundo donde las máquinas interactúan entre sí?

Hedera es donde convergen la inteligencia artificial y la tecnología blockchain. Los agentes requieren un sistema de pagos nativo de internet: programable, global, interoperable y capaz de operar de forma autónoma. Hedera opera a la velocidad de las máquinas: operaciones confirmadas en segundos, comisiones menores a un centavo, tokens nativos sin la sobrecarga de contratos inteligentes.

**El desafío:** diseñar soluciones que permitan a los agentes:

- Interactuar y transaccionar entre sí de forma autónoma
- Realizar pagos a comercios, servicios y plataformas
- Operar dentro de entornos empresariales (compras, optimización de costos, automatización financiera)
- Participar en economías digitales descentralizadas
### Premios — $1,500 USD Total

|**Lugar**|**Premio**|
| --- | --- |
|1° Lugar|$300 USD|
|2° Lugar|$200 USD|
|Pool Prize|$1,000 USD — todos los proyectos que cumplan los requisitos mínimos entran al pozo compartido|
### Requisitos Minimos para Calificar

- Utilizar el **Hedera Agent Kit** o el **Hedera SDK** para construir el/los agente(s)
- Repositorio público en GitHub con README que incluya: descripción del proyecto, instalación, arquitectura, tecnologías utilizadas y descripción del flujo de pago

### Ideas para Inspirarse — Hedera
- **API de pago por uso (x402)** — Convierte una API en una de pago por uso sin API keys ni suscripciones
- **Flujo de micropagos** — Un agente que paga por recursos de cómputo, data o inferencia en tiempo real
- **Garantías automatizadas** — Agente que retiene fondos, verifica condiciones vía Oracle o HCS y libera pagos automáticamente
- **Agente DeFi** — Monitorea precios, tokens, ejecuta operaciones o administra portafolios usando Hedera Transaction Service
- **Administrador de suscripciones** — Maneja pagos recurrentes con Hedera Scheduled Transactions (cancelaciones, renovaciones, devoluciones)
- **Agent-to-Agent Marketplace** — Agentes registran servicios en OpenClaw ACP, negocian entre ellos y pagan con HBAR o tokens HTS automáticamente

## Beexo Connect — Hackathon
### Descripcion
Mini Apps de desarrolladores de la comunidad. Conectá cualquier dApp con wallets Beexo usando el provider **EIP-1193 estándar**. Una sola línea de código para acceder a millones de usuarios.

Un proyecto puede participar en **Rootstock y Beexo Connect simultáneamente** si cumple ambos requisitos. Los bonos de participación son independientes.
### Premios — $500 USD Total

|**Premio**|**Monto**|
| --- | --- |

|Bono participación (x8) — primeros 8 proyectos en presentar integración|$50 USD c/u = $400 USD total|
|**Total**|**$500 USD**|
### Requisitos Tecnicos Minimos
El proyecto debe integrar el **SDK JS de Beexo Connect de forma funcional y demostrable en la demo** — no solo declarada.

```bash
npm install xo-connect
```

```javascript
import { XOConnectProvider } from 'xo-connect';
const provider = new XOConnectProvider();
```
### Capacidades del SDK

|**Capacidad**|**Descripcion**|
| --- | --- |
|**EIP-1193 compatible**|Provider estándar compatible con ethers.js v5.7.2+. Integración directa como Web3Provider sin configuración extra|
|**Multi-chain**|Soporte nativo para Bitcoin, Ethereum, Rootstock, BNB Chain, Polygon, Arbitrum y más|
|**Message signing**|EIP-191 (personal_sign) y EIP-712 (typed data)|
|**Debug panel**|Panel de depuración integrado para testear la Mini App antes de publicarla|

Como el SDK es EIP-1193 estándar, cualquier dApp construida con ethers.js o wagmi puede integrarse con cambios mínimos — puede ser tan simple como cambiar el provider.

## Checklist Rapido para Equipos
### Antes de empezar
- Definir el track (o tracks) en los que van a participar

- Registrarse en DoraHacks

- Crear repositorio público en GitHub

- Confirmar al menos 1 integrante presencial en el evento
### Durante el hackathon
- Aprovechar las mentorías (ver horarios arriba)

- Asistir a los workshops del track elegido

- Validar la idea con usuarios reales (encuestas, entrevistas)

- Grabar el video demo a medida que avanzan (no lo dejen para el último momento)
### Antes del cierre (viernes 17:00 hs)
- Subir a DoraHacks con al menos 30–40 minutos de anticipación

- Repositorio público con README completo

- Demo funcional accesible vía link

- Video demo subido a YouTube (o link público)

- Pitch deck en PDF

- Evidencia de validación de mercado

- Cumplir el requisito técnico mínimo del track (contrato desplegado, agente corriendo, integración demostrable, etc.)
